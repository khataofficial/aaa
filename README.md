# My Khata

Customer udhaar / stock / profit / bills khata app (PWA).

- Host: saari files kisi bhi static hosting (Netlify, Vercel, GitHub Pages) par daalein, HTTPS zaroori hai.
- Install: Chrome/Edge mein address bar ka Install icon, ya app ka "Install My Khata" banner. Phone par "Add to Home screen".
- Theme: `pro-theme.css` (colors/header yahin se badlein).
- Ads backend: agar ads par "function not found" error aaye to `supabase_ads.sql` Supabase SQL Editor mein run karein.
